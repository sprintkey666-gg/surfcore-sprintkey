# 更新日志（公开发布版）

本文件只记录**本 fork 相对上游的可见改动**。完整开发流水在私有工作区，不随仓库公开。

## 2026-11-03

### 悬浮窗 / 桌宠 0.12.17

- **记忆真的通了**：QQ、B站、悬浮窗会话、陪伴字幕共用一张记忆卡；新增「最近很要紧的」段，重要约定不会再被「最初的日子」里的老记录挤掉（按重要度排，同分比事情发生的时间）。跨端最近对话窗口放宽到 30 条 / 48 小时。
- **皮肤**：「皮肤 ›」右键菜单 / 设置页可以换形象包、导入文件夹或 `.tgz`、试播；内置 `dsh-pet`（MIT，按需下载）与随仓的 `sprintkey-fish`（网页 figure 包）。
- **互动监测**：可选开关，每 20 秒看一眼你在用什么窗口、改哪个文件、听什么歌，显示在气泡里；右键「监测 ›」。
- **气泡**：修掉被桌宠视频层盖住导致不出现的问题，改深色卡片 + 尾巴 + 4 行折叠，「试一下气泡」可以立刻验证。
- **动作不再闪**：双层 idle 常驻 + 动作层，等新视频首帧解出来才交叉淡入，动作播完先淡出再换。
- 字幕窗不闪不跳、隐藏到托盘不再留残影（0.12.15 起）。

## 2026-11-01

### 悬浮窗 0.12.0

- 气泡不再被窗口边缘裁切，长文本会自动换行并向上/向下找空间。
- 已读水位：同一段近况不会每次打开都重新弹。
- 双击气泡可查看原图。
- 与 QQ 近况互通：QQ 侧刚聊过的话题可以在悬浮窗里接着看。

### 发图：图文同一条消息

- 「配一句话」不再被驳回：文字气泡 + 原生 QQ 表情两条发出，或按配置合成一条图文消息。
- QQ 表情按原生表情发送/收藏，不再退化成 `[表情: 描述]` 文本。
- 新增 `scripts/test-pic-auto.mjs`、`scripts/test-pic-wiring.mjs` 回归。

### 语音包 voice-local 1.1.1

- 新用户首次安装默认使用本 fork 的语音包（含新音色与 RVC），不再回落到上游原始包。
- 安装/升级时保留 `.venv-rvc`，避免每次重装都重新下载模型。

### 文档

- 新增 [`docs/sprintkey/FEATURES.md`](sprintkey/FEATURES.md)，按「入口 / 代码 / 配置 / 验证」列出本 fork 的功能。

## 2026-10-31

### 全量记忆卡备份

- 本地镜像 + 增量同步，可自定义目录；按天定时，关机错过下次启动补一次。
- 可把全量卡私聊发给主人（只发 `config.json` 的 `admin.qq` / `ownerQQ`，不发群）。
- 代码：`src/memory-backup.js` + 桥接 `GET/POST /api/socialV2/memory-card-backup`。

### QQ 签名 / 空间动态

- 四项模式：关闭 / 自动（AI 按「温度」决定）/ 每 1 天 / 每 3 天 / 每 7 天。
- 空间动态可选可见范围（所有人 / 好友 / 仅自己）。
- 代码：`src/self-expression.js` + `set_self_longnick` / `send_qzone_msg`。

### 日记

- 本地 Markdown，目录可自定义；默认每 1 天写一篇，关机错过下次启动补写。
- 可选私聊发给主人，只发 `admin.qq` / `ownerQQ`，不发群。
- 代码：`src/diary.js` + 桥接 `GET/POST /api/socialV2/diary`。

### 目录选择器

- 设置页不再依赖 Windows 原生选目录框；自绘选择器能列出全部盘符、进入子目录、手输路径。

### Sprintkey 子设置分页

- 「Sprintkey扩展插件」从一页 8 个折叠分组改成 8 个二级页签，一页一个子设置。
- 记忆页重复的跨会话开关改为跳转按钮。
